The PowerPoint in `output` contains 11 main slides with a 10-minute timing plan, followed by three Q&A/reference slides. Speaker notes are embedded and supplied separately as Markdown. Rehearse aloud to adjust the pacing to your speaking speed.

The instructor's template has not yet been supplied. These project slides are ready to append; this deck does not claim to include that template.

The editable deck was created with Artifact Tool; its package, declared layout, fonts, native tables, and import were checked. Slides were rendered for visual review. It has not been inspected in the Microsoft PowerPoint application.
