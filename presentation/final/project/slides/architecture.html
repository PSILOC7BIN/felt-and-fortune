How it’s built

Small stack, no dependencies

Browser

Single-page app

HTML, CSS, JavaScript. The survey, path, and lesson player live in learn.js.

Server

Python standard library

Auth, permissions, simulations, and the learning-path API.

Storage

SQLite

Accounts, bankrolls, plans, lesson progress, and an XP log.

engine.py: basic strategy, Hi‑Lo, indices, and the Monte Carlo simulator.

coach.py: the survey, planner, and question generators; tracks.py: four 30-lesson tracks.

Backup slide (hidden): show it if asked how it’s built. The architecture is deliberately small for a solo project. The browser runs a single-page app in plain HTML, CSS, and JavaScript; the new learning section lives in its own module. The server is Python using only the standard library, so there’s nothing to install. It handles accounts, permissions, simulations, and the new learning-path API. SQLite stores everything, including plans, lesson progress, and an XP log for streaks. The domain logic sits in two modules: engine.py for the blackjack math and coach.py for the survey, planner, curriculum, and question generators.
