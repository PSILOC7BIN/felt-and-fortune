Challenges and decisions

What was hard, and what I chose

Scope

Copying an existing tool wasn’t possible or worthwhile. Building an original product was.

AI approach

A language model vs. explicit rules. Rules won on cost, correctness, and explainability.

Correctness

Hand-written quizzes can drift from the charts, so questions are generated from the engine.

Accessibility

Bright colors and playful motion still need contrast, keyboard support, and reduced motion.

About 60 seconds. A few things were genuinely hard. Scope: my first plan was to closely match an existing tool, but its signed-in features weren’t available and a copy wouldn’t have been my own work, so I built an original product instead. The AI approach: I weighed connecting a language model against writing explicit rules, and chose rules for cost, correctness, and explainability. Correctness: if I had hand-written every practice question, sooner or later one would contradict the strategy chart, so questions are generated from the same engine. Accessibility: a bright, playful style is easy to get wrong, so I checked contrast, added keyboard shortcuts for every answer, and turned off animation for people who prefer reduced motion.
