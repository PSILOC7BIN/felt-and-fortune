Live hands, flashing cards, the 3D tray, timed true counts, and full mini-shoes, with up to about 25 interactions per lesson.

Every answer comes from one strategy engine, and missed questions come back.

About 55 seconds. Lessons used to be mostly multiple choice. Now each one teaches an idea and then has you use the real tool: deal yourself live hands, count cards as they flash past, read the 3D discard tray, convert to a true count against a timer, size your bet, and in the later units play full mini-shoes that chain all of that together. Lessons run up to about twenty-five interactions, and the concept questions got harder too, like hourly standard deviation, N-zero, and how risk of ruin changes with bankroll. Every answer comes from the same strategy engine as the charts, so a lesson can never disagree with the rest of the site. Get one wrong and it comes back at the end of the lesson, like in Duolingo.
